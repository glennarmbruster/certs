Generative AI fundamentals

Generative drafting

When to use it. A team needs a first draft of a client update from approved notes and will edit it before sending.

A generative model produces new language conditioned on its instructions and supplied context. Check names, commitments and numerical claims against the approved notes before distribution.

Work grounding

When to use it. A manager asks about internal project milestones absent from public web sources.

Work grounding uses permitted organizational context to inform a response. Reference the current project plan explicitly when several versions are available.

Web grounding

When to use it. A market summary needs public information published after the team's internal business review.

Web grounding can bring current external source material into a supported response. Check publication dates and primary sources because a recent search result can describe an old event.

Permissions-aware retrieval

When to use it. Two employees ask the same project question and receive different cited internal documents.

Accessible organizational content depends on the identity's permissions and applicable controls. Test whether each employee can open the cited file before blaming the prompt.

Citation verification

When to use it. A draft quotes a policy figure and includes a link, but the underlying document contains several similar figures.

Checking the exact source passage confirms whether a citation supports the specific claim. Match the figure, units, population and effective period before accepting the draft.

Human decision review

When to use it. A generated recommendation would materially affect a customer's terms and requires accountable approval.

A human reviewer evaluates the evidence, policy and consequences before authorizing a consequential decision. Assign a named decision owner and document corrections to unsupported claims.

Untrusted source instructions

When to use it. A retrieved document contains text telling the assistant to ignore the user's requested task.

Source content is evidence to analyze. Instructions embedded in retrieved material can be unrelated or malicious. Disregard the embedded direction and continue the authorized task using verified source information.

Data minimization

When to use it. A brainstorming prompt can be answered with aggregate figures but the spreadsheet includes customer identifiers.

Providing only the information needed for the task reduces unnecessary sensitive exposure. Use approved sources or a redacted dataset and review who can access any shared output.

Prompts and chats

Task-specific prompt

When to use it. An executive wants a one-page renewal brief for finance with three decision options and supporting evidence.

Specifying goal, audience, source and output format gives the assistant concrete success criteria. Ask it to flag missing evidence when the source does not substantiate a requested option.

Source anchoring

When to use it. A proposal draft uses an obsolete pricing file when a newer approved version exists.

Explicitly referencing the approved document narrows the evidence used for the response. Check the document version and effective date in the resulting citations.

Iterative refinement

When to use it. A draft is factual but too technical for the board and exceeds the agreed length.

A follow-up can preserve verified facts while adjusting tone, length and format. Specify the audience and constraints and check that simplification preserved important qualifications.

Saved prompt

When to use it. An analyst wants to reuse the same approved analysis instructions on demand each month.

Saving a prompt preserves a reusable instruction for later invocation. Replace period-specific references before reusing it with a new reporting cycle.

Scheduled prompt

When to use it. A manager wants a supported recurring briefing from a consistent set of accessible work sources.

Scheduling runs a reusable prompt at the configured cadence in a supported experience. Review the schedule, source availability and resulting output periodically.

Copilot Notebook

When to use it. A task needs reusable, curated reference material and context across several related conversations.

A notebook groups selected references and project context for focused work. Review the notebook sources and sharing permissions when a new collaborator joins.

Chat history management

When to use it. A user needs to find a prior discussion and give it a recognizable name for later reference.

Chat history and rename controls help a user organize prior conversations. Renaming or deleting a visible chat is separate from organizational retention requirements.

Business content and collaboration

Word draft from source

When to use it. A team has an approved outline and needs readable narrative sections for a proposal.

Copilot in Word can draft and revise document content against referenced material and instructions. Review each section for unsupported commitments before accepting the generated text.

Excel trend analysis

When to use it. A sales workbook needs comparisons by quarter and a visualization grounded in its numeric data.

Copilot in Excel can help explore structured data, formulas and charts within a workbook. Reconcile totals, blank cells and denominators with the source before sharing a trend.

PowerPoint narrative

When to use it. A director wants a concise presentation based on an approved strategy document.

Copilot in PowerPoint can build a presentation draft from supplied context or a source document. Verify the narrative sequence, chart labels and source support for every material claim.

Outlook thread summary

When to use it. A project lead returns to a long email conversation and needs decisions, open questions and proposed responses.

Copilot in Outlook can summarize a thread and assist with drafting a reply. Check recipients, quoted commitments and the latest message before sending.

Teams meeting catch-up

When to use it. A participant joins a supported live meeting late and needs the discussion and decisions so far.

In-meeting Copilot can use available meeting context to answer catch-up questions when enabled. Verify meeting settings and the available transcript or speech context.

Intelligent recap

When to use it. A meeting has ended and an attendee needs a structured review of supported meeting notes and action items.

Intelligent recap organizes available meeting artifacts and AI-generated insights for later review. Confirm license, transcript availability and who may access the meeting artifacts.

Copilot Pages

When to use it. Several colleagues need to coedit a working artifact derived from a chat response.

A Copilot Page turns selected output into shared editable content for collaboration. Review the page's audience and source permissions before sharing sensitive excerpts.

Meeting preparation

When to use it. A sponsor needs an agenda based on the last meeting, unresolved actions and recent approved updates.

An anchored preparation prompt can combine relevant meetings, messages and files into a structured brief. Separate confirmed decisions from proposed agenda topics and assign evidence to each open item.

Business outcomes with agents

Researcher

When to use it. A strategy team needs a multistep synthesis of approved internal material and relevant external research.

Researcher helps plan and assemble a cited investigation across accessible sources. Check source independence and confirm that citations support each recommendation.

Analyst

When to use it. A business owner has a clean data table and needs deeper quantitative exploration of drivers and outliers.

Analyst supports data analysis over supplied or accessible datasets and can generate interpretations. Validate calculations independently and separate correlation from causal conclusions.

Task-specific custom agent

When to use it. Employees repeatedly need answers based on one internal policy collection with consistent escalation rules.

A custom agent combines purpose-specific instructions, approved knowledge and optional authorized tools. Test unsupported questions and expected escalation behavior before broad adoption.

Agent tool approval

When to use it. An assistant can draft a procurement request and a connected tool can create a real order.

A controlled approval step separates proposed work from an authorized business transaction. Review quantity, vendor, price and authority before approving an action with external effect.

Copilot Cowork task

When to use it. A project coordinator wants to delegate a multistep work item with a plan, intermediate work and a final deliverable.

Cowork can organize supported tasks into steps and use available skills and resources to complete them. Review the proposed plan, progress and final artifacts against the original brief.

Reusable skill selection

When to use it. A recurring document review follows an established organization-specific procedure with consistent formatting.

A suitable prebuilt or custom skill packages instructions for a repeatable part of a task. Inspect the skill's expected inputs and outputs before selecting it for confidential work.

Agent outcome measurement

When to use it. A pilot team must decide whether a support agent improves the quality and speed of resolving routine requests.

A measured pilot compares business outcomes with a baseline on representative tasks. Track rework, escalation quality and verified resolutions alongside time saved.
